# Community beta testing — DayZ Xbox / Microsoft Store

**Who:** We need 3–5 consenting DayZ Xbox/Microsoft Store PC community-server owners using Nitrado. You do not need DayZ installed on your test computer. This is a **free, independent, read-only experimental project**, not a live ESP, teleport, freecam or invisibility tool.

## Privacy comes first

- **Never send or publish Nitrado tokens, service/server IDs, IPs, player names, account/device IDs, raw ADM/RPT logs, private SQLite databases or identifying screenshots.**
- Only share the anonymous aggregate JSON generated by `--probe` or `beta-report`, and review it before posting. Avoid posting unredacted errors, full URLs or stack traces.
- Use a least-privilege token from your own Nitrado account if possible. Keep it on your own computer; revoke temporary tokens after testing. No maintainer needs remote access.
- Nothing calls write APIs or modifies characters, files, bans or live server state. Do not use `--include-rpt` in these tests.

## Round A: without DayZ or Nitrado

Install Python 3.10+, download/clone this repository, open a terminal in the repository root:

```bash
python -m pip install -e .
dayz-observe selftest
dayz-observe ingest samples/SYNTHETIC_dayz.ADM --db observatory.db
dayz-observe beta-report --db observatory.db
dayz-observe dashboard --db observatory.db
```

Open http://127.0.0.1:8765 on the same computer. Test opening the dashboard and choosing a synthetic player. Press Ctrl+C to close it.

## Round B: on your own Xbox Nitrado service, optionally

Use your *own* service ID in place of `YOUR_ID`. Do not share either token or ID.

Windows PowerShell:

```powershell
$env:NITRADO_TOKEN = Read-Host 'Nitrado token'
dayz-observe nitrado YOUR_ID --probe
Remove-Item Env:NITRADO_TOKEN
```

macOS/Linux:

```bash
read -rs NITRADO_TOKEN; export NITRADO_TOKEN; echo
dayz-observe nitrado YOUR_ID --probe
unset NITRADO_TOKEN
```

This reads server metadata and the *names of remote log files locally* to count ADM/RPT files but **only prints anonymous counts**. It does **not** download logs or read player data. Sharing these counts is optional.

If the check fails, report only a sanitized category: 401, 403, 404, 429, network/timeout, unsupported service or other.

## Round C: owner opt-in — locally processed ADM, never uploaded

After Round B succeeds and with owner consent:

```bash
dayz-observe nitrado YOUR_ID --dry-run --out private-logs --db observatory.db
dayz-observe nitrado YOUR_ID --out private-logs --db observatory.db
dayz-observe beta-report --db observatory.db --server YOUR_ID
```

Only the last aggregate JSON can be shared after manual review. Keep `private-logs/` and `observatory.db` on your computer. No RPT download is needed.

## Report findings

Go to [GitHub Issues > New issue](https://github.com/chrishotza/DayZConsoleObservatory/issues/new/choose) and choose **Community beta report**. Mention the test round, operating system, Python version, whether it worked and your actual administrative needs. Raw logs and credentials are never required.

**No independent live Xbox/Nitrado beta validation has been completed yet.** Offline tests are not a guarantee that your host supports the integration.
